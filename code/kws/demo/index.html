Speech Enhancement for Robust Keyword Spotting

This demo presents examples from our speech enhancement pipeline for robust keyword spotting (KWS). Each example contains a spoken keyword mixed with real-world background noise at different signal-to-noise ratios (SNRs). In the noisy condition, the keyword recognition model produced an incorrect prediction. After enhancement using an SGMSE model trained on our project dataset, the correct keyword was successfully recovered. These examples illustrate how speech enhancement improves noise robustness and enables more reliable keyword recognition.
